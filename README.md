# AeroIntelli — Premium Organic Agritech Platform

AeroIntelli is a state-of-the-art, zero-chemical, closed-loop vertical farming platform. We merge organic aeroponics, smart recirculating aquaculture systems (RAS), and AI crop intelligence to cultivate food that is purely organic—grown without pesticides, herbicides, or synthetic fertilizers.

This repository hosts the official corporate landing and teaser page for the upcoming Q4 2026 launch.

## 🚀 Key Technologies Previewed

- **Organic Aeroponics**: Soilless growth towers misting OMRI-listed organic nutrients directly to root structures, saving 90% water compared to conventional systems.
- **RAS Aquaculture**: Intelligent, closed-loop aquaculture ecosystems keeping water recirculating cleanly without synthetic treatments or waste run-off.
- **AI Decision Systems**: Real-time computer vision analysis tracking leaf temperature, color index, and root health to predict yields and optimize crop metrics.

## 📁 Repository Structure

- `index.html` - The modern, dark-forest themed corporate coming soon page, fully optimized for SEO and social sharing meta targets.
- `style.css` - Custom-designed agritech-inspired styling featuring high-contrast layout grids, fluid scaling, and interactive reveal elements.
- `app.js` - Lightweight client-side scripts managing intersection-based scroll animations, stats counters, cookie consent flags, and waitlist submission validation.
- `assets/` - Brand image assets, including the official logo and favicon.

## 🛠️ Local Development & Setup

Simply clone the repository and open `index.html` in any modern web browser to view the application:

```bash
# Clone the repository
git clone https://github.com/krishanth7/aerointelli.git

# Navigate into the project folder
cd aerointelli

# Open index.html (Mac/Linux)
open index.html

# Open index.html (Windows)
start index.html
```
